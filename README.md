# 📱 Mobile Phone Sales Analysis Dashboard – Power BI

## Project Overview
This project is developed using Microsoft Power BI to analyze mobile phone sales data and generate meaningful business insights through interactive dashboards.

## Objectives
- Analyze total sales and profit.
- Understand monthly sales trends.
- Compare sales performance across brands.
- Identify top-performing cities.
- Analyze customer payment preferences.
- Understand sales based on mobile models and gender.

## Dashboard Features
1. Total Sales – 83.98M
2. Total Profit – 4.68M
3. Total Quantity – 2K
4. Total Orders – 792
5. Monthly Sales Trend
6. Sales by Brand
7. Profit by Brand
8. Sales by City
9. Sales by Payment Mode

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## Interactive Filters
- Brand
- City
- Payment Mode
- Model
- Gender

## Key Insights
The dashboard helps analyze sales performance, identify profitable brands, compare city-wise sales, and understand customer purchasing patterns.
